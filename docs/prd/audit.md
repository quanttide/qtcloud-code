# 全量审计功能

## 功能定位

全量审计对整个代码库进行系统性审查，了解当前状况，识别技术债务。

## 核心能力

### 代码质量评估

- 模块级质量分析
- 代码复杂度检测
- 依赖关系分析

### 问题识别

- 不符合最佳实践的代码模式
- 潜在的性能问题
- 安全漏洞隐患

### 重构清单生成

- 按优先级排序
- 标记问题严重程度
- 提供修复建议

## 使用场景

1. 项目接管时全面了解代码状况
2. 版本发布前整体质量检查
3. 定期技术债务清理
4. 制定重构计划时获取依据

## 输出内容

- 问题列表（按优先级）
- 代码质量评分
- 重构建议报告

## 与重构的关系

全量审计是重构的起点：
1. 审计发现问题
2. 制定重构计划
3. 按优先级逐步重构
4. 验证重构效果
