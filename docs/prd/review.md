# 增量评审功能

## 功能定位

增量评审对新提交的代码进行即时评审，防止问题累积，保持代码质量。

## 核心能力

### 代码检查

- 代码风格规范检查
- 语法和逻辑问题检测
- 与现有代码的一致性检查

### 即时反馈

- 提交前自动评审
- 问题实时提醒
- 修复建议提示

### 持续监控

- 跟踪代码质量变化
- 防止问题回归
- 保持质量基线

## 使用场景

1. 代码提交前的自动检查
2. Pull Request 评审辅助
3. 开发过程中的即时反馈
4. CI/CD 流程集成

## 输出内容

- 问题列表（即时）
- 通过/不通过状态
- 修复建议

## 与重构的关系

增量评审是重构过程中的质量保障：
1. 重构前评审发现问题
2. 重构后评审验证效果
3. 防止重构引入新问题
4. 保持代码质量稳定
