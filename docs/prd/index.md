# 量潮编程云产品需求文档

## 产品定位

量潮编程云（QtCloud Code）帮助开发者通过**持续重构**提高工程质量。

**核心理念**：雪花编程法（受雪花写作法启发）

## 雪花编程法

### 什么是雪花编程法

雪花写作法（Snowflake Method）是一种从简单到复杂的写作方法：
1. 一句话概括故事
2. 扩展成一段话
3. 扩展成一页大纲
4. 逐步完善成完整小说

**雪花编程法**有两种应用方式：

**正向应用（构建）**：
1. 从最小可行代码开始
2. 逐步扩展和完善
3. 每一步保持可运行、可验证

**反向应用（重构）**：
1. 从混乱的复杂代码开始
2. 提炼核心逻辑，简化结构
3. 拆分细节，降低复杂度
4. 持续改进，逐步清晰

### 实践特色

雪花编程法的独特之处：

1. **反向重构思维**：不是一味扩展，而是先简化核心，再拆分细节
2. **文档即代码**：把文档架构当作代码来重构，同样的方法论适用
3. **实践验证理论**：用雪花编程法写雪花编程法的文档，边做边改
4. **边做边迭代**：发现问题立即调整，不等到完美才开始

### 为什么需要雪花编程法

传统重构的问题：
- 一次性大规模重构风险高
- 难以把握重构的边界
- 容易引入新问题

雪花编程法的优势：
- 小步快跑，降低风险
- 每步可验证，保持稳定
- 渐进式改进，易于管理
- 可正向构建，也可反向重构

## 核心功能

三个核心功能支持持续重构：

- **全量审计**：系统审查整个代码库，识别技术债务 → [详细说明](./audit.md)
- **增量评审**：即时评审新代码，防止问题累积 → [详细说明](./review.md)
- **重构**：雪花式持续改进，提高工程质量 → [详细说明](./refactor.md)
