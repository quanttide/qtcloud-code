# 量潮编程云产品需求文档

## 产品定位

量潮编程云（QtCloud Code）帮助开发者通过**持续重构**提高工程质量。

**核心理念**：雪花编程法（受雪花写作法启发）

## 雪花编程法

### 什么是雪花编程法

雪花写作法（Snowflake Method）是一种从简单到复杂的写作方法：
1. 一句话概括故事
2. 扩展成一段话
3. 扩展成一页大纲
4. 逐步完善成完整小说

**雪花编程法**将这个思想应用到代码重构：
1. 从最小可行代码开始
2. 逐步扩展和完善
3. 每一步保持可运行、可验证
4. 通过持续重构提高质量

### 为什么需要雪花编程法

传统重构的问题：
- 一次性大规模重构风险高
- 难以把握重构的边界
- 容易引入新问题

雪花编程法的优势：
- 小步快跑，降低风险
- 每步可验证，保持稳定
- 渐进式改进，易于管理

## 核心功能

### 全量审计

对整个代码库进行审查，了解当前状况。

**用途**：
- 识别代码质量问题
- 发现技术债务
- 生成重构清单

### 增量评审

对新代码进行即时评审，防止问题累积。

**用途**：
- 代码提交前检查
- 即时反馈问题
- 保持代码质量

## 重构工作流

```
发现问题 → 制定计划 → 小步重构 → 验证测试 → 提交
```

**雪花式迭代**：
1. 先重构核心模块
2. 再重构周边模块
3. 最后处理边缘模块
4. 循环往复

## 架构原则

1. **最小改动**：每次重构保持小步快跑
2. **可验证性**：每步改动都能测试验证
3. **可回滚性**：支持快速回退
