# 量潮编程云产品需求文档

## 概述

量潮编程云（QtCloud Code）致力于提升Python代码质量，解决模块级代码审计问题。通过规则引擎和评审工具，帮助开发者编写清晰、简洁、高质量的代码。

## 产品定位

- **核心定位**：提升Python代码质量，解决模块级代码审计问题
- **关键价值**：
  - 规则引擎驱动的Python代码审核（无需大模型）
  - 反向思考原则："用最少的代码表达最多的业务问题"
  - 评审工具解决圈复杂度问题
  - 智能文档工程提升写作和文档清晰度

## 核心功能

### 代码审计规则引擎

基于规则引擎的Python代码审计系统，判断代码是否符合最佳实践。

**主要能力**：
- 识别不符合最佳实践的代码模式
- 生成问题列表并提供修复建议
- 支持增量代码和存量代码审计

### Review评审工具

代码审查命令行工具，专注于圈复杂度问题解决。

**主要能力**：
- 增量代码评审
- 存量代码评审
- 逐步推进高层次设计问题

## 工作流程

```
代码提交 → 规则引擎分析 → 问题列表生成 → 用户Review → 代码改进
```

## 架构原则

1. **最小侵入**：减少对现有Coding CLI标准的修改
2. **灵活扩展**：支持评审工具和文档工程的灵活升级
