# 贡献指南

qtcloud-code-cli 的贡献流程与规范。工作范式与项目知识见 [AGENTS](./AGENTS.md)。

## 修改与提交

提交信息使用约定式提交，描述用中文，类型以 `feat`（新增）、`docs`（文档）、`chore`（维护）、`fix`（修正）为主。

每次改动默认提交并推送，不必等待指令；仅当明确说明「只提交不推」时，才停在本地。

## 测试

```sh
# 单元测试 + 集成测试
cargo test

# 覆盖率（目标 >90%）
cargo llvm-cov

# 自举验证
cargo run -- review .
cargo run -- audit .
```

### 覆盖策略

基准：总体行覆盖 ≥ 90%（当前 92%）。

| **类型** | **目标** | **方法** |
|:--|:--|:--|
| 纯函数 | ~100% | 直接测阈值、解析逻辑 |
| 文件级检测器 | >90% | 各语言 parser + 场景覆盖 |
| 项目级检测器 | >90% | 拆出纯函数单独测 |
| CLI 错误路径 | ~80% | 集成测试覆盖主要路径，余留 5% 不追 |

## 文档

对用户可见的变更同步更新 [CHANGELOG](./CHANGELOG.md)，方向或阶段调整同步 [ROADMAP](./ROADMAP.md)。

文档遵循《量潮科技文档格式章程》，要点为格式克制（能用段落即不用列表，能用列表即不用表格）、标题不超过三级且一级标题全文唯一、代码块必须标注语言、中文引号使用直角引号「」。
